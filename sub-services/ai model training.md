# **Model Training vs Fine-Tuning**

Training and fine-tuning are related but different.

| Model Training | Model Fine-Tuning |
| ----- | ----- |
| Develops model behaviour from the selected training approach | Adapts an existing trained model |
| Can require larger training datasets | Can work with more targeted datasets |
| Greater training effort may be required | Can reduce some initial training requirements |
| Suitable where a new model is required | Suitable where an existing model can be adapted |
| Greater control over the full training lifecycle | Builds upon previously learned representations |

The correct approach depends on data, model availability, required performance and project constraints.

→ potentially faster inference

→ possible performance trade-offs

# **Model Quantisation**

Quantisation is one approach that can reduce the numerical precision used by a model.

A simplified relationship is:

**Higher Numerical Precision**

→ **Quantisation**

→ **Lower Precision Representation**

→ **Potential Reduction in Memory / Compute Requirements**

The impact on model quality needs to be evaluated rather than assumed.

Quantisation is therefore a trade-off between model efficiency and acceptable output performance.

# **Model Pruning**

Pruning removes selected model weights or structures that contribute relatively little to the model's output.

A simplified process is:

**Trained Model**

→ **Identify Less Important Parameters**

→ **Pruning**

→ **Smaller / More Efficient Model**

→ **Re-Evaluation**

The model should be evaluated after pruning to determine whether the resulting performance remains suitable.

# **Model Drift**

Model drift occurs when the relationship between inputs and expected outputs changes over time.

Potential causes include:

* Changing user behaviour  
* Market changes  
* Operational changes  
* New products  
* Different data sources  
* Seasonal behaviour

A model that performed well during initial development may therefore become less effective later.

Data drift occurs when production input data changes from the data used during training.

Monitoring can identify changes in:

* Data distributions  
* Feature values  
* Category frequencies  
* Input patterns

Significant changes may require further investigation and potentially model updates.

# **Frequently Asked Questions**

### **What are AI model training services?**

AI model training services prepare data and train machine learning models to perform defined tasks such as prediction, classification, ranking or other data-driven functions.

### **What is AI model optimisation?**

AI model optimisation is the process of improving a trained model against objectives such as accuracy, inference speed, model size, memory consumption, throughput or production efficiency.

### **What is the difference between model training and model optimisation?**

Model training teaches a model patterns from data. Model optimisation improves how the trained model performs against defined quality, efficiency or deployment requirements.

### **What is the difference between model training and fine-tuning?**

Training can involve developing a model around the selected architecture and dataset, while fine-tuning adapts an existing trained model to a more specific dataset or task.

### **How much data is required to train an AI model?**

There is no universal amount. Data requirements depend on the model, task complexity, data quality, number of output classes and whether an existing model can be adapted.

### **What is model quantisation?**

Quantisation reduces the numerical precision used by a model, which can reduce memory or compute requirements. The effect on model quality should be evaluated for the specific application.

### **What is model pruning?**

Model pruning removes selected weights or structures that contribute relatively little to the model's output, with the aim of improving model efficiency while maintaining acceptable performance.

### **How are AI models evaluated?**

Models are evaluated using metrics appropriate to the task, such as accuracy, precision, recall, F1 score, prediction error, ranking quality or business-specific measures.

### **Can an existing AI model be optimised?**

Yes. Existing models can be assessed for performance issues involving accuracy, latency, model size, resource usage, drift or deployment constraints.

### **Can trained models integrate with existing software?**

Yes. Trained models can often be connected with existing applications through APIs, backend services or dedicated machine-learning components.

### **Can AI models be deployed in the cloud or on-premises?**

Models can be prepared for different deployment environments where the architecture, infrastructure and project requirements support them, including cloud or on-premises environments.

### **Can AI models run on edge devices?**

Some models can be optimised for edge deployment where model size, latency, memory and device-compute requirements allow it.

### **Why do AI models need monitoring after deployment?**

Production data and operating conditions can change. Monitoring helps identify performance degradation, model drift, data drift, latency issues and other production problems.

### **How much does AI model training and optimisation cost?**

Cost depends on data preparation, model complexity, training requirements, compute resources, experimentation, optimisation, integration, deployment and ongoing monitoring.

### **How long does AI model training and optimisation take?**

The timeline depends on data readiness, model architecture, training duration, experimentation, evaluation, optimisation requirements and production integration.
