# **Frequently Asked Questions**

### **What are mobile app design services?**

Mobile app design services define how a mobile application should work and look through UX research, information architecture, user journeys, wireframes, prototypes, UI design, usability validation and developer handoff.

### **What does a mobile app design company do?**

A mobile app design company helps structure and design the user experience and interface of an application, from early product requirements and user journeys through wireframes, prototypes and detailed UI designs.

### **What is mobile app UX design?**

Mobile app UX design focuses on how users navigate and interact with an application, including information architecture, user journeys, task flows, navigation and usability.

### **What is mobile app UI design?**

Mobile app UI design defines the visual and interactive interface of the application, including typography, colours, layouts, buttons, forms, navigation, icons and component states.

### **What is the difference between UI and UX for mobile apps?**

UX focuses on how the mobile experience works and how users complete tasks. UI focuses on how that experience is visually and interactively presented through individual screens and components.

### **Do you create mobile app wireframes?**

Yes. Mobile wireframes can define screen structure, navigation, functionality and user flows before detailed visual design begins.

### **Can you create an interactive app prototype?**

Yes. Important app screens can be connected into interactive prototypes so user journeys can be reviewed and validated before full development.

### **Do you design for iOS and Android?**

Mobile app design and development are separate but connected services. Design defines the product experience and interface, while development implements the approved experience as working software.

The timeline depends on product complexity, number of screens, user roles, research, wireframing, prototyping, UI design, platform requirements, usability testing and stakeholder feedback.
